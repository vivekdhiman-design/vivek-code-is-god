# vivek-code-is-god

A simple Todo app organized with an MVC-style structure.

## Structure

```text
.
├── app.js
├── package.json
├── controllers/
│   └── todoController.js
├── models/
│   └── todoModel.js
├── routes/
│   └── todoRoutes.js
└── views/
    ├── index.html
    └── style.css
```

## Run

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3000
```
